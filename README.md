# BookParadise

A responsive static bookstore website built with HTML, CSS, and vanilla JavaScript.

## Pages

- `index.html` - home page and featured books
- `product.html` - searchable, filterable book catalogue and shopping bag
- `about.html` - about the bookstore
- `contact.html` - contact form demo

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. No build step or package installation is required.

The shopping bag is saved in browser local storage. Checkout and the contact form are front-end demos; they do not send payments, orders, or messages to a server. Fonts and book-cover photos load from Google Fonts and Unsplash.
